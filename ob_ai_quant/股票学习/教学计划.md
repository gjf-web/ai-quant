# Module 2：Probability, Expected Value and Decision Making

这一章对你的事件驱动策略极其重要。

学习：

Expected Value  
Variance  
Conditional Probability  
Bayes' Theorem  
Scenario Analysis  
Skewness  
Fat Tail  
Risk of Ruin

核心公式：

\[ E[R] = \sum_i p_iR_i. \]

然后进入：

\[ P(A|D) = \frac{P(D|A)P(A)} {P(D)}. \]

我们会直接用 FDA、财报、政策事件作为案例。

最终解决：

> “成功概率很高”为什么不等于“值得买”？

以及：

\[ \boxed{ p_{\mathrm{your}} > p_{\mathrm{market}} } \]

才可能代表真正的 edge。

# 最终毕业项目：建立你的 Investment Operating System

整个课程最后，你需要自己写出一份真正可以执行的规则。

第一部分：

\[ \boxed{\text{Idea Generation}} \]

我从哪里找机会？

产业链、新闻、技术、政策、screening。

第二部分：

\[ \boxed{\text{Research}} \]

行业是什么？

公司是什么？

竞争优势是什么？

关键 driver 是什么？

第三部分：

\[ \boxed{\text{Expectations}} \]

市场现在预期什么？

我的预期哪里不同？

第四部分：

\[ \boxed{\text{Catalyst}} \]

为什么市场会在未来：

\[ 30\sim60\text{ days} \]

改变看法？

第五部分：

\[ \boxed{\text{Timing}} \]

成交量、趋势、relative strength、options positioning 是否支持？

第六部分：

\[ \boxed{\text{Sizing}} \]

最多亏多少钱？

EV 多大？

Correlation 多大？

第七部分：

\[ \boxed{\text{Exit}} \]

Thesis failure  
Target reached  
Catalyst completed  
Momentum broken  
Better opportunity

分别怎么处理？

第八部分：

\[ \boxed{\text{Review}} \]

每笔交易记录：

Prediction  
Probability  
Reason  
Result  
Error Type。

最后把错误分成：

\[ \text{Analysis Error} \]\[ \text{Probability Error} \]\[ \text{Timing Error} \]\[ \text{Sizing Error} \]\[ \text{Execution Error}. \]

这一点非常重要，因为：

> 亏损交易不一定是错误交易，盈利交易也不一定是正确交易。

例如：

\[ P(\text{success})=80\% \]

但最后失败，这仍然可能是一笔 mathematically correct bet。

反过来：

\[ P(\text{success})=10\% \]

却碰巧暴涨，也不能证明决策是正确的。
