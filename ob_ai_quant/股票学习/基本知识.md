# Module 1-Return, Risk, Benchmark and Alpha

简单收益率$\[ R_{t,t+1} = \frac{P_{t+1}-P_t+D_{t+1}}{P_t}, \]$。P是股价D是股息
我们用这个版本$\[ R_{t,t+1} \approx \frac{P_{t+1}-P_t}{P_t}. \]$
描述长期财富增长速度的量叫 **Geometric Mean Return（几何平均收益率）**
$$\[ 1+\bar R_G = \sqrt{(1+R_1)(1+R_2)}. \]$$
如果资金从 \(W_0\) 经过 \(T\) 年变成 \(W_T\)，那么 **Compound Annual Growth Rate** 定义为
$$\[ \boxed{ CAGR = \left( \frac{W_T}{W_0} \right)^{1/T}-1. } \]$$
**Log Return（对数收益率）**$\[ \boxed{ r_t = \ln\frac{P_{t+1}}{P_t} = \ln(1+R_t). } \]$
**Volatility（波动率）**：$\[ \boxed{ \sigma = \sqrt{ \operatorname{Var}(R) }. } \]$

对于随机收益，在一定近似下：(算术增长率和几何增长率与volatility的关系)
$\[ \boxed{ g \approx \mu-\frac12\sigma^2, } \]$
其中：$\[ \mu=\text{arithmetic expected return}, \]$
而$\[ g=\text{approximate geometric growth rate}. \]$

最基本的 linear factor model 是：$\[ \boxed{ R_P-R_f = \alpha + \beta(R_B-R_f) + \epsilon. } \]$
其中：$\[ R_f=\text{risk-free rate}, \]\[ \beta = \frac{ \operatorname{Cov}(R_P,R_B) }{ \operatorname{Var}(R_B) }. \]$
注意：跑赢QQQ并不意味着你的组合比QQQ好，可能是因为你承担了更多的风险beta。alpha高才是真正意义上的好

在最简单的单因子模型里：$\[ \boxed{ \alpha = E[R_P-R_f] - \beta E[R_B-R_f]. } \]$
它代表不能由 benchmark exposure 解释的 excess return。

定义 **Tracking Error**：
$\[ \boxed{ TE = \sigma(R_P-R_B). } \]$
也就是 active return 的标准差。
然后定义 **Information Ratio**：
$\[ \boxed{ IR = \frac{ E[R_P-R_B] }{ \sigma(R_P-R_B) }. } \]$
它问的是：
> 每承担一单位相对于 QQQ 的主动风险，你获得多少超额收益？

correlation并非总是不变，在危机和市场大跌时由于种种原因，很多股票都会被抛售

risk分为三层：1.单一股票2.主题危险3.市场危机

# Module 3-Market Mechanics
股票不是买的人多就涨，卖的人多就跌
Buy at Ask；Sell at Bid
限价单提供流动性，市价单消耗流动性

股票价格是由边缘价格控制的，绝大部分的股票是不动的，这对小盘股及其重要
liquidity是理解短期股价的核心
Market impact： 你的订单本身会改变价格（尤其是对于流动性低的股票）
一个关键点：限价单可以撤回，这意味着你可能会被表面的订单欺骗
成交量本身意义不大 关键是相对成交量（Relative Volume）

不确定性上升=流动性提供者需要更多的补偿

流动性降低导致：1.价格区间增加spread大 2.市场反作用增大MarketImpact大

VWAP：Volume Weighted Average Price：今天市场实际成交的大部分股票，大约发生在什么价格附近？这对机构很重要，但不一定是庄家的成本钱
不要有主力成本价这个概念：因为有很多主力机构

Support、Resistance正确理解：在这个价格附近有很多卖家，这个价位是很多人的回本价于是很多人想回本于是supply增加，当然也可能是历史high从而卖，但总的来说在support附近，卖家很多

Breakout意味着什么？假设股票长期稳定在某一区间（建立了equilibrium），这意味着在这个区间两个端点附近有很多supply来阻止继续上涨或下降。但如果突然股价上涨且RVOL明显增加，需求超过supply，旧的平衡被打破了。但是也可能存在False Breakout，这需要你辨别。

大机构买卖股票都是长期执行的，拆分成很多小分股，所以连续多日的异常成家+相对强势比单日巨量更值得研究。

机构买入股票应该会出现sell pressure不断吸收出现：回调相对较浅。下跌成交量相对小，反复回升，VWAP上升，强势收盘。Accumulation吸筹

机构卖出股票Distribution派发，persistent supply出现：反弹屡屡失败，成交量高但价格没有上涨，收盘疲软，相对弱势


Effort（Volume） vs Result（Price）

Absorption：如果很多人不断market sell，aggressive selling up，但是P基本不变，这意味下面存在强大的passive bids。sell orders 被limit buyers持续吸收。

Market Maker：目的是控制股价，通过不断的bid和ask，但是他存在一个关键风险就是库存风险（inventory risk）当存货越来越大时就可能降价来鼓励别人买走

options dealer和Market Maker虽然都具有市场调节功能，但是二者仍有区别，
Delta：option value对股票价格的一阶敏感性 Gamma表示二阶敏感性，前者速度后者加速度

Gamma Squeeze：投资者大量购买短期限call，而dealer则是short call，那么dealer为了hedge，会买入大量股票，导致股价上涨，然后又导致call增加，形成正反馈，这种情况下价格短期可能明显偏离基本面。但注意High Call Volume 不一定会导致Gamma Squeeze

Short Selling（卖空）：借股票，卖出，到期后再买回来还Profit=卖价-买价-服务费，卖空的亏损是无上限的！
call（做多）：借钱买股票，到期后卖掉还钱，Profit=卖价-买价-服务费，最多亏本金

做空指标：
	Short Interest：被卖空但尚未平仓的shares，就是等着股价下跌卖空人准备买的股票
	short Float：卖空股占流通股的比例，高代表看跌（这只是市场判断并非事实）
	short squeeze逼空 原因股价突然上涨，卖空者为了对冲风险买入股票，股票继续上涨
	Days to Cover DTC=short interest/日均volume 表示如果所有的short都想正常平仓需要多少交易日，DTC越大流动性越大
	short squeeze出现条件：1.高short interest2.流动性紧缺3.正向catalyst4.price momentum。注意发生short squeeze时你应该买入股票！

short covering和fundamental buying要区分

short squeeze和Gamma Squeeze也不是同一个东西：short squeeze的核心买家是short seller，而Gamma Squeeze的核心买家是option dealer hedging。当然这两者可能同时发生。

紧记，暴涨过后一般会是暴跌

liquidation cascade：某些价格区间存在很多限价卖单比如支撑位，于是当突破支撑位时这些限价单提供流动性使价格继续下跌形成持续下跌


对做波段而言：正向催化+高卖空+突破位+RVOL那么未来几天可能同时有fundamental buying+ momentum buying + short covering。但是若只有short covering 那么一旦squeeze exhaustion价格可能会迅速回落

以后分析为什么价格会涨：1.基本面2.平仓要求3.流动性4.技术流（动量交易）从而判断这轮涨价是否能持续

几个独立的变量：fundamental、expectations Revision、price、volume、positioning、valuation

产业链决定where、基本面决定which company、expectation决定is there mispricing 、catalyst决定why now， market dynamics决定when and how
